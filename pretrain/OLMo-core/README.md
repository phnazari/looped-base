# OLMo-core

A copy of [OLMo-core](https://github.com/allenai/OLMo-core) v2.5.0 (Apache-2.0, see `LICENSE`) with looped
models added (`src/olmo_core/nn/looped/`) and the sandwich block of Huginn (`SandwichTransformerBlock` in
`src/olmo_core/nn/transformer/block.py`). It is installed by `uv sync` at the repository root.
